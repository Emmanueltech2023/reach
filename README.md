# REACH

> **R**esources · **E**ntrepreneurs · **A**ccess · **C**apital · **H**orizons

A global verified investment and startup ecosystem connecting high-potential innovators with active capital allocators across borders.

---

## The Core Framework

- **R — Resources**: Proprietary deal rooms, standardized legal templates, AI startup scoring, and real-time performance analytics.
- **E — Entrepreneurs**: Visionary founders and engineering innovators building high-growth tech ventures across emerging and global hubs.
- **A — Access**: Direct, KYC-verified access connecting entrepreneurs with active global capital allocators without gatekeepers.
- **C — Capital**: Angel networks, syndicate funds, VC partners, and Web3 crypto rails ready to deploy into high-conviction deals.
- **H — Horizons**: Unlocking cross-border scale, multi-region market entry, and limitless international growth opportunities.

---

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: Next.js (App Router) & React 19
- **Styling**: Tailwind CSS & Vanilla Theme Tokens
- **Backend / Auth**: Supabase (PostgreSQL, Realtime, Storage)
- **Media CDN**: Cloudinary
- **Emails**: Resend API
- **Web3 / Crypto**: Wagmi & Viem
